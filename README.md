# Music Momentum

An iOS guitar-practice app. Pick a song from Apple Music, slow it down to a speed you can actually play (30–100%), mark the points and clips you're working on, and loop clips back to back.

SwiftUI + SwiftData + MusicKit. Swift 6 with `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`, deployment target iOS 26.4. Playback needs a real device with an Apple Music subscription; the simulator builds and runs the unit tests.
